# wiki 스텁 — Orca 내장 브라우저로 E2E 실측하기 (JSP·jQuery 스택)

> `/harness-retro` 드레인 시 Step2 "운영 gotcha→wiki" 라우팅으로 페이지 생성.
> 제안 파일명: `wiki/orca-browser-e2e.md`
> 관련 클러스터: `[[gates-verify-present-code-only]]`(있는 코드만 보는 게이트의 사각), `[[vite-stale-served-source-windows]]`·`[[vue-immediate-watch-template-ref]]`(렌더 실측 계열)

## 증상 / 왜 필요한가

렌더 영향 변경은 정적 검증(vue-tsc·tld 태그 대조·lint)만으로 종결하면 안 된다. 그런데 JSP + jQuery + 자체 컴포넌트 스택엔 Playwright/vitest 같은 러너가 없어 **"자동화 인프라 없음 → 사람 E2E 이관"** 으로 굳는다. 그 결과 게이트 6종 전원 PASS 후 사람이 화면을 열자 결함이 나오는 사고가 실제로 있었다(2026-08-24, 팝업 인라인 노출).

**Orca ADE 가 설치된 환경이면 인프라가 있다.** 브라우저 자동화 CLI가 내장돼 있고 Bash만 있으면 몰 수 있다.

## 핵심 이점 — 사용자 로그인 세션을 그대로 쓴다

`chrome-devtools-mcp` 는 **별도 Chrome 프로필**로 뜬다. 사내 관리자 콘솔처럼 로그인이 필요한 화면은 계정을 따로 받거나 쿠키를 주입해야 한다.

Orca 내장 브라우저는 **사용자가 ADE에서 이미 로그인해 둔 세션을 공유**한다. `/_/login` 으로 이동시켰더니 `/_/console#/dashboard` 로 리다이렉트됐다 — 이미 로그인 상태였다. 계정 정보를 주고받을 필요가 없다.

## 사용법

```bash
O="$LOCALAPPDATA/Programs/orca/resources/bin/orca.exe"   # ⚠ 머신 종속 — 탐지 래퍼 경유할 것
"$O" tab create --url "http://localhost:9090/_/login"
"$O" tab list                       # pageId 확인
"$O" eval --expression "JSON.stringify({url:location.href})"
"$O" find --locator text --value "메뉴명" --action click
"$O" screenshot --format png --json > shot.json          # base64 를 JSON에서 추출
```

전체 명령: `tab create/list/show/current/close`, `goto`, `snapshot`, `click`, `fill`, `type`, `select`, `hover`, `keypress`, `scroll`, `back`, `reload`, `screenshot`, `eval`, `wait`, `check`, `find`, `get`, `is`, `mouse *`, `set device/offline/headers`

## 함정 6종 (전부 실측)

### 1. `snapshot` 은 깨진다 — `eval` 로 대체하라

`orca snapshot` 이 **매번** `runtime_unavailable`("The Orca runtime closed the connection before responding") 로 실패했다. `orca status` 는 그 직후에도 `runtimeState: ready` 였다 — 런타임은 멀쩡하다. 접근성 트리 직렬화가 큰 페이지에서 죽는 것으로 보인다.

→ `eval --expression` 으로 DOM을 직접 질의한다. 오히려 필요한 값만 뽑아 반환 크기도 작다.

### 2. `screenshot` 은 간헐 실패 — 재시도 래핑 필수

같은 `runtime_unavailable` 이 `screenshot` 에도 뜬다(1회차 실패 → 2회차 성공). 결과가 파일이 아니라 **JSON 안의 base64** 다(`--filePath` 옵션 없음).

```bash
for i in 1 2 3; do
  "$O" screenshot --format png --json > s.json
  python -c "...base64 추출·저장..." && break
  sleep 3
done
```

### 3. 자체 컴포넌트는 합성 MouseEvent 를 무시한다 — 컴포넌트 API 를 써라

`cr` 그리드/트리는 `dispatchEvent(new MouseEvent('click'))` 에 반응하지 않는다. 행을 더블클릭해 수정 팝업을 여는 시도가 조용히 실패했다.

→ 컴포넌트 API 를 직접 호출한다:
```js
domainMgrGrid.selectRecord(0); _editPopup.open(1);   // 행 선택 → 수정 팝업
```
트리 노드는 `.cr_treeNodeText` 의 네이티브 `.click()` 은 먹는다. 단 **접힌 부모를 먼저 펼쳐야** 자식이 보인다(`offsetParent === null` 로 판정).

### 4. `cr:input` 라디오/체크박스는 `label` 을 클릭한다

실제 `<input>` 위에 label 오버레이가 얹혀 있어 `input.checked = true` 만으로는 시각 상태가 안 따라온다.
```js
document.getElementById('flagName1_w').querySelector('label').click();
```
(`_w` 접미 래퍼 div 규약 — `basic-console-page.js` 가 이 규약에 의존)

### 5. `cr:datepicker` 표시 입력칸은 `readonly` — 달력을 클릭할 수밖에 없다

```html
<input id="cr_dp_<id>_disp" type="text" value="2026.09.09" readonly>
<input id="<id>" type="hidden" value="20260909">
```
타이핑 불가. 절차: `_disp` 클릭 → `.cr_calendarPrev.month` 를 N회 클릭 → 날짜 셀 클릭.

⚠ **날짜 셀 셀렉터를 `td.cr_calendarNormal` 로 좁히면 실패한다.** 일요일은 `cr_calendarSun`, 전/다음달은 `cr_calendarOther` 다. 5월 31일(일요일)을 못 찾아 `NOCELL` 이 났다.
```js
[...document.querySelectorAll('td.cr_calendarDay')]
  .filter(e => e.offsetParent !== null
            && !/cr_calendarOther/.test(e.className)
            && e.innerText.trim() === '31')[0].click();
```

### 6. 프로그램적 `setDate()` 는 이벤트를 안 쏜다 — 이게 오히려 무기다

`CrLibDatePicker` 의 `setValue`/`setDate` 는 값만 넣고 `onChangeFunc` 을 호출하지 않는다(달력에서 사용자가 고른 경로만 호출).

그래서 **"화면 값은 바뀌었는데 아직 조회는 안 한 상태"** 를 정확히 만들 수 있다. 엑셀 내보내기 경로가 자체적으로 기간 보정을 하는지 검증할 때 이게 결정적이었다 — 목록 검색을 한 번도 안 거친 채 내보내기를 눌러 그 경로의 보정 로직만 단독으로 찔렀다.

## 부수 노하우

- **토스트 캡처**: `cr.growl.showMessage` 를 래핑해 배열에 기록(원본 위임 유지). 렌더된 DOM 은 사라지지만 문구는 남는다.
- **전송 파라미터 검증**: `$.fileDownload` 를 래핑해 `data` 를 캡처하면 실제 요청값을 볼 수 있다. UI 표시값과 전송값이 갈리는 버그를 잡는다.
- **다운로드 산출물 검증**: `openpyxl` 로 xlsx 를 열어 머리말·데이터 행을 단언. `sharedStrings` 인덱스를 손으로 파싱하면 틀리기 쉬우니 openpyxl 을 쓴다.
- **API 직접 호출은 UI 보정을 우회한다.** 서버가 별도 상계를 갖는 설계면 `fetch` 로 만든 결과와 화면 결과가 다르다. **테스트는 UI 경로로.**
