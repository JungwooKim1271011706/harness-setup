## 전체회귀 (tester-runtime) — 매 구현 체인 밖

```
진입 경로는 둘뿐 (자동 호출 없음 — ADR-0002 D1)
  ① 사용자 수동 "회귀 돌려"
  ② 전체회귀 부채 트리거 안내를 사용자가 수락
        └ finalizer ①이 render한 ⚠ 강력권장
          (N≥5커밋 또는 공용 프레임워크 모듈 변경)
              │
              ▼
      tester-runtime (통합 + 전체회귀 1회)
              │
     PASS ────┴──── FAIL
      │              │
 regression-debt.sh  실패 도메인 판정
 reset (부채 0)      → 해당 developer 반환
                     (부채 유지)
```

> 위 FAIL 3분기의 `tester-runtime 재실행`은 **환경문제 진단** 경로다. 부채/수동 트리거와 별개.
